Three ways into BPS data.

Use the browser interface for exploration or the command line for repeatable data work.

01

Local web app

Explore subjects, variables, publications, and static tables in a browser UI that runs entirely on your computer.

02

Statistics to CSV

Export dynamic tables into one-row-per-value CSV files with variable, region, year, period, and value fields ready for analysis.

03

Publication PDFs

Bulk-download BPS publications by subject. Interrupted runs resume cleanly by skipping files already on disk.

Start with one key and Python 3.

Clone the repository, save your BPS WebAPI key as .bps_key, then launch the local app. There are no third-party packages to install.

Your API key stays local.

The key file is ignored by Git and requests are sent directly from your computer to the BPS API.

1 · Clone
git clone https://github.com/hengkykurniawan/bps_download.git
cd bps_download
2 · Add your API key
# Create .bps_key and paste your BPS WebAPI key inside
3 · Launch
python bps_app.py
